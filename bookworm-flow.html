2 · User Journey Flows — Frontend ↔ Backend
App Start
Page load
Frontend
StoreContext initialises — reads bw_user & bw_cart_id from localStorage
Generates a UUID cart ID if none stored (persists across sessions)
HomeView mounts → triggers catalog + recommendations load
Backend
GET /catalog/categories
GET /catalog/shelves/bestsellers
GET /catalog/shelves/new-launches
GET /recommendations/personalized
GET /cart/{cartId}
Authentication
Login / Register
Frontend
LoginModal component opens (triggered by nav or protected action)
On success → user object saved to bw_user localStorage + StoreContext
Wishlist auto-loads for the newly logged-in member
Backend — AuthController
POST /auth/login → returns AuthResponse (memberId, name, email, giftPoints)
POST /auth/register → 201 Created
GET /members/{memberId}/wishlist → reload wishlist books
Browse & Search
HomeView
Frontend
Search bar, Language / Format / Price dropdowns update searchFilter state
useEffect debounces → triggers API call when any filter is active
Left sidebar categories set searchFilter.category
BookCard grid renders results / shelves depending on active filter
Backend — CatalogController
GET /search?q=&category=&language=&format=&minPrice=&maxPrice=&sortBy= → paginated BookDto[]
CatalogServiceImpl uses JPA Specification for dynamic multi-attr filtering
Supports sort: RELEVANCE · PRICE_LOW_HIGH · PRICE_HIGH_LOW · NEWEST
Book Details
BookDetailView
Frontend
viewBookDetails(bookId) sets selectedBookId + switches view
Parallel load: book info · related books · reviews
Wishlist heart button calls toggleWishlist → requires login
Add to Cart button calls addToCart(bookId, 1)
Star rating form + textarea → submit review
Backend
GET /catalog/books/{bookId} → BookDto
GET /recommendations/related/{bookId} → BookDto[]
GET /reviews/book/{bookId} → ReviewDto[]
POST /cart/{cartId}/items → CartDto
POST /reviews → ReviewDto
POST /members/{memberId}/wishlist
DELETE /members/{memberId}/wishlist/{bookId}
Cart
CartCheckoutView
Frontend
Cart items list with +/− qty buttons and trash remove
Coupon code input → apply discount; display savings message
Redeem Gift Points toggle → deducts up to 50% of subtotal
Price summary: subtotal + 5% tax − coupon − points = final
Proceed to Payment button — requires logged-in user
Backend — CartController + CouponController
GET /cart/{cartId} → CartDto (items, subtotal, itemCount)
PUT /cart/{cartId}/items/{itemId}?quantity=N → updated CartDto
DELETE /cart/{cartId}/items/{itemId} → updated CartDto
POST /coupons/calculate {code, orderAmount} → {discount, finalAmount}
GET /members/{memberId}/addresses → AddressDto[]
Checkout & Payment
CartCheckoutView
Frontend (multi-step)
Step 1 — Select or create delivery address
Step 2 — Create Order → receive orderId
Step 3 — Payment modal: choose method (Credit Card / UPI / Wallet / COD)
Step 4 — Process payment → success confirmation screen
On success: cart cleared, navigate to Orders view
Backend — OrderController + PaymentController
POST /members/{memberId}/addresses → AddressDto (if new)
POST /orders {cartId, memberId, addressId, couponCode, redeemGiftPoints} → OrderDto
POST /payments/process {orderId, paymentMethod, amount} → PaymentResponse
OrderServiceImpl converts cart items → order items; updates stock
PaymentServiceImpl records payment; awards gift points on success
Order History
OrdersView
Frontend
Loads all orders for logged-in member on mount
Cancel Order button — 48-hour SLA window (confirm dialog)
Buy In Again button — re-adds past items to current cart → redirects to Cart
Backend — OrderController
GET /orders/member/{memberId} → OrderDto[] with nested items & books
POST /orders/{orderId}/cancel → OrderDto (status: CANCELLED; refund gift points)
POST /orders/{orderId}/buy-again {targetCartId} → updated CartDto
Wishlist
WishlistView
Frontend
Loaded on login via StoreContext.refreshWishlist()
Heart icon on BookCard / BookDetail toggles membership in wishlist
WishlistView shows full saved books grid
Backend — WishlistController
GET /members/{memberId}/wishlist → BookDto[]
POST /members/{memberId}/wishlist {bookId}
DELETE /members/{memberId}/wishlist/{bookId}
Writers
WritersView
Frontend
Shows writer subscription list for logged-in member
Backend — AuthController
GET /members/{memberId}/writers → WriterDto[]

5 · Key Feature Highlights

🛒 Cart Persistence

UUID cart ID stored in localStorage — survives page refresh & logout
Cart created lazily on backend on first item add
Shared cart ID across guest and logged-in sessions

💰 Loyalty: Gift Points

Points awarded by PaymentService on successful payment
Redeem up to 50% of order subtotal at checkout
Points refunded on 48h cancellation

🔖 Coupon Engine

POST /coupons/calculate returns exact discount amount
Stacks with gift point redemption in price summary
Invalid/expired coupon returns 4xx with message

🔍 Multi-Attr Search

Simultaneous filters: text · category · language · format · price range
4 sort modes: Relevance / Price↑ / Price↓ / Newest
JPA Specification for dynamic query building

📦 Order Lifecycle

48-hour cancellation SLA enforced server-side
"Buy In Again" re-orders any past order into active cart
Full order history with item-level book details

⭐ Reviews & Discovery

Star rating (1–5) + comment; logged-in only
Personalized recommendations derived from order history
Related books panel on every Book Detail page
